# Privacy Policy

Effective date: July 26, 2026

Voice Notify for Codex performs local audio playback only.

- It does not make network requests.
- It does not collect telemetry or analytics.
- It does not inspect, persist, or transmit prompts, messages, transcripts,
  tool inputs, tool outputs, account data, or personal information.
- The hook reads only the `hook_event_name` field needed to select a bundled WAV.
- Local settings contain only enabled state, voice, language, event toggles, and
  playback interval.
- Runtime state contains only a playback timestamp used to prevent overlap.

Questions can be filed at
https://github.com/battle-doll/codex-voice-notify/issues.
